# Backlog MVP

## P0

- Zamknac kontrakt protokolu engine <-> web.
- Zrobic cienki backend dla auth, treningow i zapisu sesji.
- Zaimplementowac engine z handshake, heartbeat i podstawowymi eventami.
- Zrobic onboarding webowy z detekcja engine.
- Zrobic jeden ekran treningu i jeden ekran wyniku.

## P1

- Dodac kalibracje opoznienia.
- Dodac dashboard progresu.
- Dodac crash reporting i telemetry.
- Dodac instalator engine.
- Zostawic rozbudowany tuning wizualny i polishing UI na etap po domknieciu mechaniki i stabilnosci MVP.

## P2

- Dodac system streakow i prostych nagrod.
- Dodac wiecej typow treningu.
- Dodac platnosci lub limity darmowe.

## Definicja gotowosci P0

- Dziala pierwsza sesja treningowa od logowania do zapisu wyniku.
- Engine i web komunikuja sie stabilnie.
- Krytyczne bledy sa raportowane.
- Zespol potrafi wypuscic nowa wersje bez recznych obchodow.
